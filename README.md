# Macaroon Launcher 배포

`launcher/windows/`에는 Windows 설치 프로그램, `launcher/linux/`에는 Linux x64 실행 패키지를 보관합니다. `details.json`의 `launcher_version`과 `launcher_update_v2`는 런처 자동 업데이트에서 사용합니다. 설치파일 URL은 검증한 커밋에 고정하며 SHA-256을 함께 제공합니다.

게임과 창작물은 [Macaroon Workspace](https://macaroon.snode.kr)에서 관리합니다.

1.0.86: 네이티브 동영상 재생 및 배경 페이드, 채팅 전송 포커스 유지, 라이브러리·탐색·채팅 이미지 상태 유지, 채팅 로딩 표시와 이미지 메시지 여백을 개선했습니다. 샌드박스 기능은 포함되지 않습니다.
